# arabidopsis-gwas-pleiotropy

Code and processed data accompanying the manuscript:

> **A conundrum of pleiotropy: GWAS-derived pleiotropy is weakly negatively associated with co-expression network centrality in *Arabidopsis thaliana***

This repository provides the scripts, processed datasets, and manuscript outputs required to reproduce the analyses presented in the manuscript.

# Data

The `data/` directory contains the external datasets and processed files required for the analyses.

## External datasets

Included in this repository:

- AraPheno phenotype metadata
- Arabidopsis co-expression network metrics

Not included (must be downloaded separately):

- AraGWAS Catalog database

# Scripts

Scripts should be run in numerical order.

| Script | Purpose |
|---------|---------|
| **01_process_aragwas.R** | Extract SNP-level associations from the AraGWAS database and map SNPs to TAIR10 genes |
| **02_build_gene_trait_effects.R** | Build gene-level trait and effect-size tables |
| **03_calculate_pleiotropy.R** | Calculate Hill (q = 1) and other gene-level pleiotropy metrics |
| **04_analyze_network_centrality.R** | Compare GWAS-derived pleiotropy with co-expression network centrality |
| **05_analyze_detectability.R** | Evaluate GWAS detectability using co-expression representation and tissue specificity |
| **06_analyze_busco_enrichment.R** | Test enrichment of GWAS genes among BUSCO genes |
| **07_make_figures_and_tables.R** | Generate manuscript Figure 1 and Table 1 |

Each script has a companion README describing:

- purpose
- required inputs
- outputs
- analysis details
- important notes
