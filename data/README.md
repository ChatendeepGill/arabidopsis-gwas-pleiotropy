## Data
This directory contains external and processed datasets used in the analyses of GWAS-derived gene-level pleiotropy in *Arabidopsis thaliana*.

## Directory Structure
• `external/`: Data obtained from external databases or previously published studies

• `processed/`: Data generated by filtering, cleaning, transforming, or combining external datasets

## AraGWAS Catalog
Genome-wide association data were obtained from the AraGWAS Catalog, a curated database of SNP-trait associations in *Arabidopsis thaliana*. 

The AraGWAS data used in this study included SNP-trait associations passing the permutation-based significance thresholds reported by the database. The relevant AraGWAS identifiers and association data were subsequently processed to obtain gene-level measures of pleiotropy.

The complete AraGWAS database is not redistributed in this repository. It can be accessed through the AraGWAS Catalog. Processed datasets required to reproduce the analyses are provided where permitted. 

**Source:** Togninalli et al. (2017, 2019)

## AraPheno
Trait metadata were obtained from the AraPheno database. These data included phenotype names, descriptions, and trait classifications linked to the corresponding AraGWAS studies and phenotypes. 

Relevant trait metadata and processed trait-classification tables are provided where permitted.

**Source:** Togninalli et al. (2019)

## Co-expression Network Metrics
Gene co-expression network statistics were obtained from Nocchi et al. (2024). The metrics were calculated using previously published *Arabidopsis thaliana* gene-expression datasets and included:

• node degree;

• node strength;

• closeness centrality; and

• betweenness centrality.

These data were matched to the GWAS-derived gene-level pleiotropy estimates using TAIR10 gene identifiers.

**Source:** Nocchi et al. (2024), using expression data from Papatheodorou et al. (2018)

## Tissue-specificity Estimates
Gene-level tissue-specificity estimates were obtained from Nocchi et al. (2024). Tissue specificity was measured using tau (τ), where lower values indicate broader expression across tissues and higher values indicate greater tissue specificity.

These data were used to test whether gene-expression breadth was associated with the probability that a gene was detected through GWAS. 

**Source:** Nocchi et al. (2024), using expression data from Papatheodorou et al. (2018)

## Protein-coding Gene Background
A genome-wide background set of protein-coding genes was generated from the TAIR10 *Arabidopsis thaliana* protein annotation available through Ensembl Plants.

Gene identifiers were extracted from all annotated protein-coding loci. Duplicate identifiers were removed before the resulting gene set was used as the genomic background for enrichment analyses. 

The complete TAIR10 protein annotation is not redistributed in this repository. It can be downloaded from Ensembl Plants.

**Source:** Ensembl Plants, TAIR10 annotation

## BUSCO Genes
Benchmarking Universal Single-Copy Orthologs were identified using the embryophyta_odb10 BUSCO lineage dataset. Genes classified as Complete or Duplicated BUSCOs were retained.

Transcript-specific suffixes were removed to convert transcript identifiers to TAIR10 gene identifiers, and duplicate gene identifiers were removed before analysis.

The complete BUSCO lineage dataset is not redistributed in this repository. The processed *Arabidopsis thaliana* BUSCO gene list used in the analyses is provided in the `processed/` directory.

**Source:** Manni et al. (2021)
