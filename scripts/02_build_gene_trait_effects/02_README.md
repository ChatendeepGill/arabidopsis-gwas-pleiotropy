**Purpose:** 
Apply the AraGWAS significance threshold, standardize SNP effect size within each phenotype, aggregate SNP effects within genes, attach AraPheno metadata, remove climate-related phenotypes, and collapse repeated phenotype measurements sharing the same ontology trait. 

**Inputs:**
- `results/aragwas_combined_results.csv`: Generated by `01_process_aragwas.R`
- `data/external/arapheno/phenotype_list.csv`: AraPheno phenotype metadata included in this repository

**Main Outputs:**
- `gene_trait_effects.csv`: This file contains one row per gene and ontology trait, with the mean absolute standardized effect size for each gene-trait combination.
- `gene_trait_table.csv`: This file contains one row per gene and a readable semicolon-separated list of ontology traits and rounded effect-size estimates.
- `gene_trait_collapsed.csv`: This file contains the same unique gene-trait combinations as `gene_trait_effects.csv`, with `mean_abs_beta_effect renamed` to `abundance` for downstream Hill-diversity calculations. 

**Optional Additional Output:**
- `gene_summary_std_with_phenotype.csv`: This file contains gene-level summary statistics for each individual phenotype before climate traits are removed and repeated ontology traits are collapsed. This file is not required by later analysis scripts. 

**Notes:**
- AraGWAS scores are reported as -log10(p), so score > 4 corresponds to p < 1 x 10^-4.
- Effect size values are standardized separately within each phenotype
- Climate-related phenotypes are identified by AraPheno phenotype names beginning with “clim”
- When multiple phenotype measurements map to the same ontology trait for a gene, their gene-level mean absolute standardized effect sizes are averaged.
