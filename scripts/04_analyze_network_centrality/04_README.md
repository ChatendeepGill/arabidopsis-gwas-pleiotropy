**Purpose:** 
Merge gene-level GWAS-derived pleiotropy metrics with co-expression network centrality metrics, then calculate the reported Spearman rank correlations. 

**Inputs:**
- `gene_pleiotropy_hill_metrics.csv`: Generated by `03_calculate_pleiotropy.R`
- `data/external/coexpression/arabidopsis_coexpression_metrics.rds`: Gene-level co-expression network statistics included in this repository

**Main Output:**
- `merged_hill_coexp.csv`: Contains pleiotropy and co-expression network centrality metrics for genes represented in both input datasets

**Correlations:**
Spearman rank correlations are calculated between Hill (q = 1) and:
- co-expression network degree
- co-expression network strength
- co-expression network closeness
- co-expression network betweenness

**Notes:** 
- Only genes represented in the pleiotropy **and** co-expression datasets are retained
- Hill (q = 1) and network metrics are analyzed on their original scales
- Plotting and figure generation are handled separately from the correlation analysis
