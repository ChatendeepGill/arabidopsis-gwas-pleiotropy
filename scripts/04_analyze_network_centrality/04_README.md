**Purpose:** 
Merge gene-level GWAS-derived pleiotropy metrics with co-expression network centrality and tissue-specificity estimates, then calculate the reported Spearman rank correlations between Hill (q = 1) and each metric. 

**Inputs:**
- `gene_pleiotropy_hill_metrics.csv`: Generated by `03_calculate_pleiotropy.R`
- `data/external/coexpression/arabidopsis_coexpression_metrics.rds`: Gene-level co-expression network statistics included in this repository
- `data/external/tissue_specificity/arabidopsis_tissue_specificity_tau.rds`: Gene-level tissue-specificity estimates included in this repository

**Main Outputs:**
- `merged_hill_coexp.csv`: Contains pleiotropy and co-expression network centrality metrics for genes represented in both input datasets

**Additional Outputs:**
- `merged_hill_tau.csv`: Contains Hill (q = 1) and tissue-specificity estimates for genes represented in both datasets
- `spearman_correlation_results.csv`: Summary of Spearman correlation coefficients, p-values, and sample sizes for all five analyses

**Correlations:**
Spearman rank correlations are calculated between Hill (q = 1) and:
- co-expression network degree
- co-expression network strength
- co-expression network closeness
- co-expression network betweenness
- tissue specificity (mean tau)

**Notes:** 
- Co-expression correlations include only genes represented in both the pleiotropy **and** co-expression datasets with complete network centrality estimates
- Tissue-specificity correlation is calculated **independently** of co-expression network representation, using genes with valid Hill (q = 1) and mean tau estimates
- Hill (q = 1), network centrality metrics, and tissue-specificity estimates are analyzed on their original scales
- Analyses use different gene populations depending on data availability (N = 1,646 for co-expression correlations; N = 2,039 for tissue specificity) 
- Plotting and figure generation are handled separately from the correlation analysis
