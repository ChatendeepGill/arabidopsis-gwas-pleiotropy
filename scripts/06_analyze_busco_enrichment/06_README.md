**Purpose:** 
Test whether genes classified as Complete or Duplicated by BUSCO are enriched among genes with retained GWAS associations.

**Inputs:**
- `results/gene_trait_table.csv`: Generated by `02_build_gene_trait_effects.R`. Genes in this file are treated as having at least one retained GWAS association.
- `data/processed/busco/arabidopsis_busco_genes.tsv`: BUSCO output table. This file is included in the repository.
- `Arabidopsis_thaliana.TAIR10.pep.all.fa`: TAIR10 protein FASTA used to define the background protein-coding gene set. This file was obtained from Ensembl Plants and is not included in the repository. 

**Analysis:**
1. Identifies genes classified by BUSCO as **Complete** or **Duplicated**
2. Identifies genes with at least one retained GWAS association
3. Defines the background using all TAIR10 protein-coding genes
4. Compares BUSCO and non-BUSCO genes using Fisher’s exact test

The script also reports the proportion of BUSCO and non-BUSCO genes with retained GWAS associations.

**Outputs:**
Statistical results are printed to the R console. No additional results files are saved.
