**Purpose:** 
Create manuscript-ready Figure 1 and Table 1 from the final processed datasets.

**Inputs:**
- `results/gene_pleiotropy_hill_metrics.csv`: Generated by `03_calculate_pleiotropy.R`
- `results/gene_trait_collapsed.csv`: Generated by `02_build_gene_trait_effects.R`
- `results/gene_trait_table.csv`: Generated by `02_build_gene_trait_effects.R`
- `results/merged_hill_coexp.csv`: Generated by `04_analyze_network_centrality.R`

**Figure 1** contains four panels:
- **Panel A:** Distribution of Hill (q = 1) across genes
- **Panel B:** Distribution of the number of ontology traits associated with each gene
- **Panel C:** Relationship between trait richness and Hill (q = 1)
- **Panel D:** Relationship between Hill (q = 1) and co-expression network degree

Linear trend lines are included in Panels C and D for visualization. The reported statistical associations are evaluated separately using Spearman rank correlations.

**Table 1** contains the five genes with the highest Hill (q = 1) values and their corresponding gene-level pleiotropy metrics and ontology-trait summaries.

**Outputs:** 
- `figures/Figure_1.pdf`
- `figures/Figure_1.jpg`
- `results/Table_1_top_pleiotropic_genes.csv`

**Notes:**
- `gene_trait_collapsed.csv` contains one row per unique gene-trait combination. The number of rows per gene is therefore used to calculate trait richness for Panel B.
- Statistical tests are not performed in this script
