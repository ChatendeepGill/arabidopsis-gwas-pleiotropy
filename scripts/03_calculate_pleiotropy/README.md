**Purpose:**
Calculate gene-level measures of GWAS-derived pleiotropy, including trait richness, total effect magnitude, mean effect size per trait, the sum of squared effect sizes, Shannon entropy and Hill q = 1. 

**Input:**
- `gene_trait_collapsed.csv`: Generated by `02_build_gene_trait_effects.R`. The file contains one row per unique gene-trait combination. Required columns include: gene, trait, and abundance. 

**Main Output:**
- `gene_pleiotropy_hill_metrics.csv`: This file contains one row per gene and the following pleiotropy metrics:
  
&emsp;&emsp; • `trait_richness`: number of unique ontology traits associated with the gene

&emsp;&emsp; • `total_effect_magnitude`: sum of absolute standardized effect sizes across traits

&emsp;&emsp; • `H`: Shannon entropy of the within-gene trait-effect distribution

&emsp;&emsp; • `hill_q1`: effective number of equally weighted traits, calculated as the exponential of Shannon entropy

&emsp;&emsp; • `magnitude` or `sum_squared_effect`: sum of squared absolute standardized effect sizes

&emsp;&emsp; • `mean_of_means` or `mean_effect_per_trait`: mean absolute standardized effect size across traits

**Calculation Details:**

For each gene, trait-effect magnitudes are converted to proportions:

&emsp; *proportion_i = abundance_i / sum(abundance)*

Shannon entropy is calculated as:

&emsp; *H = -sum(proportion_i x ln(proportion_i))*

Hill (q = 1) is then calculated as:

&emsp; *Hill q = 1 = exp(H)*

Hill (q = 1) represents the effective number of traits based on the distribution of relative effect magnitudes. A gene whose effect is distributed evenly across traits will have a higher Hill (q = 1) than a gene whose effect is concentrated primarily in one trait.

**Notes:**
- `trait_richness` treats every associated ontology trait equally
- `hill_q1` accounts for both the number of associated traits and the evenness of their effect magnitudes
- `total_effect_magnitude` is the sum of effect magnitudes
- `sum_squared_effect` corresponds to the `magnitude = sum(abundance^2)` calculation used in the original analysis and gives greater weight to large effects
- All effect-size measures are based on absolute standardized beta values generated in `02_build_gene_trait_effects.R`
